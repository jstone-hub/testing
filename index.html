Running it

Two screens, zero infrastructure.

Everything is local to the device. Nothing is uploaded, and the booth doesn't need conference wifi to be working.

Player tablet

Open signal-vs-noise.html fullscreen. Portrait or landscape, touch or mouse — arrow keys work too, for testing on a laptop.

Second screen

Open signal-vs-noise.html#board on the big monitor. It launches straight into large-type display mode and refreshes as scores land.

Same machine as the tablet — scores live in that browser's local storage.

Staff controls

Optional name and email capture on the end screen for the raffle. Booth staff can wipe the board between days with one button.

Cards and timings are a plain array at the top of the file — edit without touching game logic.
